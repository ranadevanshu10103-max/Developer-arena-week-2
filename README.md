# Python Week 2 - Student Grade Calculator

## Project Overview

This project is a Student Grade Calculator created as part of Week 2 of The Developers Arena internship.

The program takes a student's name and marks as input and calculates the grade based on the marks. It also provides encouraging messages according to the grade.

## Features

- Takes student name as input
- Takes marks from 0 to 100
- Validates invalid marks
- Uses if-elif-else statements for grading
- Uses a function to calculate the grade
- Uses while loop for input validation
- Handles invalid numeric input
- Displays encouraging messages

## Grading System

- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: 0-59

## Setup Instructions

1. Install Python 3.x.
2. Download or clone this repository.
3. Open the project folder.
4. Run `grade_calculate.py` using Python.
